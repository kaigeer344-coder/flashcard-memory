# 冲刺角色系统设计

## 1. 功能目标

在「考试冲刺」模式设置完成后，根据用户选择的**考试类型 + 剩余天数**，生成一个专属形象和口号，让备考过程更有趣、更有爽感。

触发时机：用户完成 onboarding 的「考试冲刺设置」页后，形象立即生效，并展示在首页、学习地图等位置。

## 2. 设计原则

所有角色、卡片、装饰必须统一为 **Duolingo + 用户小鸟画风**：

- 圆润胖嘟嘟的身体
- 蓝色大眼睛、黑色瞳孔、白色高光
- 橙色小嘴和脚丫
- 米白色蓬松肚皮和脸蛋
- 柔和但不过度的软萌 kawaii 风格
- 粗黑描边、干净平涂色
- 纯白背景、居中全身、3/4 正面视角

## 7. 展示位置

1. **考试冲刺设置页**：选择考试类型和日期后，实时出现角色卡片 + 文案预览。
2. **首页课程卡片**：标题显示「称号 · 考试」，副标题保留倒计时/阶段信息。
3. **学习地图**：角色作为小导师，在底部或顶部显示一句当日鼓励语。
4. **每日任务完成后**：角色弹出战绩鼓励弹窗。
5. **冲刺完成纪念卡**：最后一天任务结束后弹出纪念卡片。

## 8. 实现方式

- 用 PNG 素材展示角色，控制单张图片在 80KB 以内。
- 在 `home-components.js` 或单独 `data/role-config.js` 中维护配置表。
- 根据 `examType + days` 映射到对应的称号、文案、角色形象。
- 将结果存入 `localStorage`，首页/学习地图读取显示。

### 10.2 冲刺完成纪念卡（优先）

#### 纪念卡视觉设计

- 尺寸：4:5（适合朋友圈/小红书分享），1080×1350px
- 风格：Duolingo + 小鸟画风，高饱和绿，粗黑描边，圆角
- 背景：放射状绿色光芒 + 白色圆点 + 淡绿色渐变
- 边框：粗黑描边 + 白色内描边 + 轻微硬阴影
- 顶部：大标题「🎉 冲刺完成！」+ 副标题「你完成了 四级 · 10天冲刺计划」
- 中部：对应角色形象（占画面 40%），角色头顶显示称号徽章
- 下部：数据面板（学习天数 / 掌握单词 / 连续打卡 / 完成率）
- 底部：纪念文案 + 完成日期 + 唯一编号 +「闪卡记忆 · 认证天才」印章
